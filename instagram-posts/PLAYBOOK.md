# Instagram投稿制作プレイブック（どうぶつ病院京都 / CUaRE）

Canvaでのフィード投稿（カルーセル形式）を、ベーステンプレートの複製・改変で作っていくための手順書。
「夏の犬の散歩を快適にする方法 やること5選」制作時の流れをベースに作成。

## ベーステンプレート

- Canvaデザイン：「フィード投稿：意外と多い誤食ワースト３」
  - design_id: `DAHDiC0dvuw`（元デザイン。直接編集しない。必ず `copy-design` で複製してから作業する）
- 構成：表紙 → コツ紹介ページ×N → まとめ（獣医師からひとこと）→ 保存訴求 → CTA
- コツ紹介ページは3種類のレイアウトパターンが混在している
  - パターンA：見出し＋本文＋アイコン付き2行ボックス（元の「第1位」ページ）
  - パターンB：見出し＋本文＋箇条書き3項目＋右下写真＋左下写真（元の「第2位」ページ）
  - パターンC：見出し＋本文＋段落のみ、写真2枚（元の「第3位」ページ）
- ブランド：CUaREロゴ、水色×グレーの配色、丸数字の見出し、右下「SWIPE」表記、左上に「現在ページ／全体ページ数」の算用数字バッジ

## 制作フロー（標準5ステップ）

### 1. 要件確認
テーマ・コツの数・写真の有無と入手方法を確認する（下記「コンテンツ依頼テンプレート」参照）。

### 2. リサーチ
健康・安全に関わる内容は必ずWebSearchで裏取りする（獣医師監修記事、公的機関の情報などを優先）。数字や「◯秒ルール」のような具体的な基準は出典を意識し、投稿内で表現がブレないようにする。

### 3. デザイン組み立て
1. `copy-design` でベースを複製
2. コツの数が元の3個と異なる場合、`merge-designs`（`insert_pages`）で該当レイアウトのページを複製 → 挿入位置がズレるので `move_pages` で正しい順序に並べ替える
3. `start-editing-transaction` → `perform-editing-operations` で全ページのテキストを流し込む（ページ単位でまとめて送るとよい）
4. ページ番号バッジは全角算用数字（１２３…）で統一する。**漢数字（一二三…）は使わない**（後述の失敗例参照）
5. 作業が多ページにまたがる場合、**最後まで一気にやらず、1〜2ページごとにサムネイルで見た目を確認する**（テキストがボックスからはみ出す・隣要素と重なる、を早期発見するため）

### 4. 写真
- **最も確実な方法**：作業用Canvaリンクをユーザーに渡し、直接ドラッグ&ドロップしてもらう
- Google Driveなどの外部リンクを使う場合、**共有設定が「リンクを知っている全員」になっている必要がある**（組織内限定共有だとCanva側から取得できず失敗する）
- **同じ素材を使い回さない**（意図がない限り）。特に注意する場面：
  - 前回投稿と同じ写真を表紙に使う → 前回投稿との差別化ができない
  - 同一投稿内の複数ページで同じ写真を使う → 手抜きに見える
  - 写真の枚数がページ数より少ない場合は、無理に埋めずテキストのみのページがあってよい（むしろ「毎ページ写真」より緩急がついて自然）

### 5. プロレビュー（納品前に必ず実施）
以下を通しで確認する：

- [ ] 全ページのテキストが今回のテーマに統一されているか（旧テーマの文章が取り残されていないか）
- [ ] ページ番号の連番・書式（全角算用数字）が全ページで一致しているか
- [ ] 本文中の数字・ルールが矛盾していないか（例：見出しは「5秒ルール」なのに本文は「3秒」）
- [ ] 隣接するテキストブロックが内容的に重複していないか
- [ ] テキストと写真・装飾アイコンが重なっていないか（特に表紙：カットアウト画像前提のレイアウトに実写真を差し込むと衝突しやすい）
- [ ] 素材（写真）が前回投稿・同一投稿内で使い回されていないか

## つまずきポイント（実例ベース）

- **ページ挿入順序**：`insert_pages` は指定位置の直後に挿入される。複数回挿入すると意図した順序にならないことがあるので、挿入後は必ずページ構成を確認し、必要なら `move_pages` で並べ替える。
- **手打ちUnicodeエスケープは事故る**：`【` のような手打ちescapeで日本語テキストを組み立てると誤字が発生しやすい（実際に「5秒」→「10秒」、「涼しい」→「液しい」等のタイプミスが発生した）。**素の日本語文字列をそのままJSONに書く**方が安全。
- **カットアウト画像→実写真の差し替えは要レイアウト調整**：表紙などで透過カットアウト画像（背景が透明で犬の形だけ残る画像）を前提にテキストやアイコンと重ねて配置している場合、それを普通の矩形写真に差し替えるとテキストを覆ってしまう。矩形写真は見出しの下に余白を確保した「写真パネル」として独立させるのが安全。
- **やり残しに注意**：ページ数が多い投稿（7〜9ページ）を作業する際、最後の数ページ（まとめ・保存訴求）の文章更新を忘れがちだった。全ページ分の操作リストを作ってから着手し、完了後に `get-design-content` で全文を読み直して漏れがないか確認するとよい。
- **写真の受け渡し**：組織のGoogle Driveは既定でドメイン内限定共有になっていることが多い。事前に「リンクを知っている全員」への変更が必要な旨を伝えておくと手戻りが減る。

## コンテンツ依頼テンプレート

この形式で情報をもらえると、そのまま流し込みやすい。

```
【テーマ】
タイトル：（例：夏の犬の散歩を快適にする方法）
サブタイトル：（例：獣医師がすすめる夏の散歩の工夫）
コツの数：（例：5）

【コツ1】
見出し：（15字以内目安。例：散歩の時間帯を選ぶ）
本文（なぜ大事か、1〜2文）：
箇条書き（2〜3項目、あれば）：
補足（具体的な数字・例、あれば）：
写真：（説明 or「なし」）

【コツ2】
（同上のフォーマットで、コツの数だけ繰り返す）

【まとめページ】
見出し：（例：獣医師からひとこと／固定でよければ省略可）
注意点・危険サインのリスト：
一言メッセージ：

【保存訴求ページ】
見出し：（例：毎日の散歩を、もっと快適に）
本文：（保存を促す一言＋相談窓口への誘導）

【写真素材】
1. 内容の説明：（どのコツに使うか、意図があれば）
2. ...
   ※共有方法：Canva下書きへの直接アップロード or 「リンクを知っている全員」に設定したGoogle Driveリンク
```

- 箇条書きや補足は無くてもOK（テンプレートのレイアウトパターンに応じて自動で調整する）
- 医療・健康に関わる数字や基準は、根拠のあるものであればその出典（記事名やURL）を添えてもらえると裏取りがスムーズ
- 写真は必須ではない。無ければテキストのみのページとして構成する
